# Docs

Overthink is an open-source sandbox for testing AI in a business environment. At its centre is Overthought & Co. Start with the [project README](../README.md). Coding agents start at [AGENTS.md](../AGENTS.md) and [ai-instructions/](../ai-instructions/README.md).

## Use it

| Doc | What it says |
| --- | --- |
| [`../ai-instructions/`](../ai-instructions/README.md) | The guides an agent follows: setup, planning, synthetic users, running, results, resetting. |
| [`../activity-generation/README.md`](../activity-generation/README.md) | Every activity action, the person profile, and the four ways in (MCP, CLI, HTTP, TypeScript). |
| [`connect.md`](connect.md) | The business's own doors for a product that calls tools itself: MCP, a web address, the web API, the jobs. |
| [`jobs.md`](jobs.md) | The ready jobs a connected AI can take, and how each is judged. |
| [`run.md`](run.md) | The optional `overthink run` twin-run tool: what it does, every figure, the limits. |
| [`audiences.md`](audiences.md) | The persona engine behind `overthink run`: customers, staff, businesses, suppliers, the public. |
| [`results-schema.md`](results-schema.md), [`live-events.md`](live-events.md) | `overthink run`'s results file and live event stream, field by field. |
| [`lab.md`](lab.md) | Experiments on the business itself (prices, policies, staffing), with repeats and a "why". |
| [`consequences.md`](consequences.md) | What every action does to the business, and which numbers are assumptions. |
